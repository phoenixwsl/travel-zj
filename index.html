每日安排

时间是参考；累了就删次要点，不补行程

D1 · 9/25｜杭州 → 宁波

  • 08:30 杭州出发，约2小时，途中服务区休息一次即可。
  • 11:00左右 到宁波，先入住/寄存行李，再吃午饭。
  • 14:00—16:30 天一阁为主，顺带月湖、鼓楼一带慢走。
  • 17:30后 吃宁波菜，可选海鲜、汤圆、年糕类；晚上有体力再去老外滩散步。
  • 当天不要再加东钱湖，把城市人文玩扎实即可。
住：天一广场 / 老外滩附近，方便步行吃饭

D2 · 9/26｜宁波 → 温州

  • 08:30 退房后去东钱湖，上午只走湖景 + 韩岭，不做完整环湖。
  • 09:00—11:00 湖边散步、韩岭老街，孩子有兴趣可多留半小时。
  • 11:00—12:15 在东钱湖附近午饭，尽量 13:00前 出发。
  • 宁波到温州约269 km / 4小时，建议中途服务区休息一次，预计 17:00左右 入住。
  • 晚上 公园路 / 五马街吃逛，重点尝鱼丸、灯盏糕、糯米饭，不再安排正式景点。
住：温州鹿城老城附近，方便夜间步行

D3 · 9/27｜温州 → 苍南

  • 08:30—10:30 江心屿；如果天气、轮渡或孩子状态不合适，就改成老城慢逛。
  • 11:00—12:00 温州午饭后直接取车。
  • 12:30—13:00 出发去苍南，县城方向约66 km / 1.1小时。
  • 14:30后 进入浙南168，选一段漂亮海岸线慢慢开，重点是停车看海、走走沙滩，不追求把整条168跑完。
  • 傍晚 找海边看日落，晚上吃海鲜，尽量早点休息。
住：炎亭或苍南海岸附近，停车方便优先

D4 · 9/28｜苍南 → 缙云仙都

  • 08:00左右 海边吃早餐、再走一小段，上午不要安排新的大景点。
  • 09:00—09:30 出发去缙云，约240—270 km / 3.5—4小时，是全程较长转场。
  • 13:00左右 抵达后先吃午饭、入住或寄存行李，稍微休息。
  • 15:00—17:30 仙都慢玩，优先朱潭山、溪边田野；倪翁洞看体力决定。
  • 晚上 吃缙云烧饼、土爽面，早点休息，为第二天晨景留体力。
住：仙都景区附近，方便第二天一早进景区

D5 · 9/29｜缙云 → 古堰画乡 → 松阳

  • 08:00—09:15 仙都晨景，补前一天没走完的轻松段。
  • 09:30—10:00 离开仙都，前往古堰画乡。
  • 中午—14:30 看瓯江、通济堰、古樟一带；古堰画乡控制在2—3小时，不要耗掉整个下午。
  • 15:30—16:00 出发去松阳，傍晚入住。
  • 晚上 松阳老街散步，吃当地小吃和家常菜，今天不再进古村。
住：松阳县城 / 老街附近，第二天出发方便

D6 · 9/30｜松阳 → 衢州

  • 08:30左右 出发去古村，首选杨家堂，上午只玩一个村，留出拍照、喝茶和慢走时间。
  • 若杨家堂限流或停车困难，就直接换陈家铺；松庄只作为备用，不为了“多打一个村”绕路。
  • 孩子如果对古村兴趣不高，可把上午改成 大木山茶园，体验会更轻松。
  • 11:30—12:30 回松阳县城午饭、休息。
  • 13:30—14:00 出发去衢州，约121 km / 1.6小时；傍晚逛水亭门、老城，晚上重点吃衢州菜。
住：水亭门 / 老城附近，方便晚饭和第二天上午

D7 · 10/1｜衢州 → 杭州

  • 起床第一件事 看衢州→杭州高速实时路况，这一天路线服从拥堵情况。
  • 如果路况正常，上午安排 孔氏南宗家庙 / 衢州市博物馆，二选一即可；时间宽裕再加第二个。
  • 11:30左右 午饭，正常情况下中午前后返杭。
  • 如果早上已经出现明显拥堵，直接取消上午景点，早餐后上高速。
  • 常态约225 km / 2.8小时，但10月1日不要按这个时间卡到家时间。
返程：实时路况优先于任何上午景点
国庆提醒：10月1日衢州返杭州不要按常态 2.8 小时卡时间；当天所有上午景点都属于“可删项”。
里程为行程规划参考值；浙南168、古堰画乡及景区内道路会增加实际驾驶里程。
