每日安排

累了就删次要点，不补行程

D1 · 9/25｜杭州 → 宁波

  • 08:30 杭州出发，午前到宁波。
  • 下午：天一阁 + 鼓楼/月湖。
  • 晚上：宁波菜；有体力再去老外滩。
住：天一广场 / 老外滩附近

D2 · 9/26｜宁波 → 温州

  • 上午：东钱湖 + 韩岭，11:00左右结束。
  • 午饭后尽量13:00前出发，约4小时。
  • 晚上：公园路 / 五马街吃逛。
住：温州鹿城老城附近

D3 · 9/27｜温州 → 苍南

  • 上午：江心屿；天气不合适就老城。
  • 午饭后去苍南，下午走浙南168漂亮短段。
  • 傍晚：海边、日落、海鲜。
住：炎亭或苍南海岸附近

D4 · 9/28｜苍南 → 缙云仙都

  • 09:00—09:30 出发，约3.5—4小时。
  • 下午：仙都，朱潭山 / 倪翁洞按体力取舍。
  • 晚上：缙云烧饼、土爽面。
住：仙都景区附近

D5 · 9/29｜缙云 → 古堰画乡 → 松阳

  • 08:00 仙都晨景，随后去古堰画乡。
  • 午后：瓯江、通济堰一带慢走。
  • 15:30—16:00 去松阳，晚上逛老街。
住：松阳县城 / 老街附近

D6 · 9/30｜松阳 → 衢州

  • 上午：杨家堂 / 松庄选1—2个。
  • 午后去衢州，约1.6小时。
  • 傍晚：水亭门、老城；晚上吃衢州菜。
住：水亭门 / 老城附近

D7 · 10/1｜衢州 → 杭州

  • 先看实时高速路况。
  • 路况正常：南孔 / 衢州市博物馆二选一。
  • 若拥堵明显：早餐后直接返杭。
返程：实时路况优先于上午景点
国庆提醒：10月1日衢州返杭州不要按常态 2.8 小时卡时间，上午景点全部可取消。
