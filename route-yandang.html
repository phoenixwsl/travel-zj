D1 · 9/26 周六｜杭州 → 宁波

约155 km · 城际约2小时

保持原计划：08:30左右出发，午前抵达；下午天一阁、月湖，晚上宁波菜。老外滩按体力决定，不再增加东钱湖。

住宿：宁波，天一广场 / 月湖 / 老外滩附近按已选酒店安排。

D2 · 9/27 周日｜宁波 → 雁荡山

约220 km · 城际约3小时
转场窗口留3–3.5小时

早餐后直接南下，不去东钱湖、韩岭。把当天主要驾驶放在上午，午饭后安顿好再玩，晚上不用继续开往温州。

08:30
宁波退房出发，中途按需休息。
11:30–12:00
预计抵达雁荡山一带；先吃午饭、停车、寄存行李。是否能提前入住需问酒店。
12:00–14:00
午饭和休息，确认当天停车、换乘、步道开放。不要为了赶表演压缩休息。
14:00–16:30
灵岩或大龙湫二选一，走景区常规开放路线。预留返回住处的时间。
16:30–18:00
回住处、晚饭、休息。当天路上耽搁就把游览再缩短，不补全景区。
天黑后
灵峰夜景可选，建议留约1小时游览，往返交通另计。先核对入园和回程安排；累了就取消。

下午怎么选

灵岩：以山谷、岩壁和古寺周边为主，路线长短按体力选，不把飞渡表演设成必看。

大龙湫：以山谷与瀑布为主，临行前看水量与步道状态。两处不同时安排。

玩法是本次时间预算下的取舍，不代表开放范围、表演时刻已经核实。

这一晚住哪里

建议先查雁荡山景区周边、响岭头一带住宿，按选定景区核对停车、接驳和到店路线。

优先能停车、安静、能吃早餐的住处；不要为拍照好看的房间临时增加一段山路。未指定酒店，也未查询实时房态或改订。

9/27动态检查：已有该日越野训练赛报名信息，涉及灵峰、灵岩等区域；这不等于景区闭园。出发前确认当日停车、步道和换乘安排。表演、缆车以及夜景的实际开放以官方公告为准，不作为行程成立的前提。查看来源与待核项

住宿：雁荡山 · 1晚，替换原方案9/27的温州住宿。

D3 · 9/28 周一｜雁荡山 → 温州 → 苍南

经温州至苍南县城约150–170 km
城际约2.5–3小时；海岸另计

今天的重点是转场和海边。不安排江心屿，也不再做一轮温州老城游览；温州只承担吃饭、休息的作用。

08:00–08:30
早餐退房，不加早间山景，直接去温州方向。
10:00左右
按导航决定是否进温州用餐。雁荡山至温州公开参考约86公里、1小时14分，计划留出进城停车余量。
10:30–12:00
早午饭和休息，找方便停车的地方。当地鱼丸、面食等按就近餐馆选择，不专门排网红长队。
12:00–13:30
去苍南方向，先按实际海边酒店定位导航。约66公里是温州至县城参考，不是到全部海滩的距离。
14:00–17:00
一片海滩 + 周边海岸短段，按住宿选炎亭附近等停留点；30–60公里只作可删的游览预算，不是任务。
傍晚
海边散步、晚饭、休息，不为追日落再跨一段海岸。风浪或管控不合适就取消沙滩活动。
温州可以跳过：若进城绕路、拥堵或没有合适停车位，就继续南下，在苍南吃饭。跳过后的里程、时间另按导航计算，不沿用上方“经温州”的估算。

住宿：苍南海岸；尽量与 A 版选择同一住宿点，方便比较，也便于D4衔接。

本日驾驶比 A 增加；轻松的前提是少逛市区、海岸不过度拉长。页面不承诺全天驾驶一定低于3小时。

D4 · 9/29 周二｜苍南 → 缙云仙都

约240–270 km · 城际3.5–4小时

与 A 相同：早餐后09:00–09:30出发，中途休息和午饭按路况安排；抵达先安顿，下午朱潭山、好溪和田野，倪翁洞可删。它仍是较长转场日，不能因为前一天轻松就把下午填满。

住宿：仙都附近。

D5 · 9/30 周三｜缙云 → 古堰画乡 → 松阳

约145–160 km · 驾驶2.5–3小时

与 A 共用这一天：仙都晨景后去古堰画乡，下午转松阳，晚上老街。前一天已看得满意时，可以取消晨景二刷；这条减负建议对两版都适用。

古堰画乡不把乘船排队、两岸游览当成零时间；若抵达晚，就缩短游览，不挤压晚上的休息。

住宿：松阳县城 / 老街附近。

D6 · 10/1 周四｜松阳 → 衢州

约121 km · 城际约1.6小时

与 A 相同：上午选一个古村，午饭后去衢州，傍晚水亭门、老城和当地菜。古村山路、停车和接驳另留时间；不要默认杨家堂堵了，陈家铺就一定好进。

两个热门村都不顺时，可以改县城休息或经确认开放后的茶园散步，不为完成打卡临时加山路。

住宿：衢州水亭门 / 老城附近。

D7 · 10/2 周五｜衢州 → 杭州

约225 km · 常态约2.8小时

与 A 相同：早餐后查导航。路况合适，南孔或博物馆选一个；否则直接返杭。不要按常态时长卡到家时间，休息和用餐另计。

返程：10月2日回杭州，不增加一天。
